Model Context Protocol

Make MCP matter:
AI agents for everyday life

MCP is a simple open standard that lets an AI assistant safely use your calendar, email, maps, notes and bank — so it can do things for you instead of only talking about them.

How it works

1 · Ask

You tell the assistant what you want in plain language.

2 · Connect

It finds the right MCP servers — small connectors for each app or service.

3 · Act

It calls their tools step by step, and shows you what it did.

4 · Stay in control

You approve sensitive actions. Every call is visible.

Try the agent

Prototype: tool calls are simulated in your browser. Nothing is sent anywhere.

What a tool looks like

An MCP server just describes its tools. Any compatible assistant can use them.

{
  "name": "calendar.find_free_slot",
  "description": "Find a free time on the user's calendar",
  "inputSchema": {
    "type": "object",
    "properties": {
      "duration_min": { "type": "number" },
      "day": { "type": "string" }
    }
  }
}
