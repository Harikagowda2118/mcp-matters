What is MCP?

The Model Context Protocol is an open standard for connecting AI assistants to apps, files and services. Think of it as USB-C for AI: one plug that works everywhere.

🔌

One standard

Build a connector once and any MCP-compatible assistant can use it.

🧰

Tools, not guesses

The AI calls real tools with clear inputs and gets real results back.

🔒

You stay in charge

Connectors do only what you allow, and sensitive actions need approval.

How it works

1 · YouAsk in plain language.
2 · AI assistantThe host app. Its MCP client picks tools.
3 · MCP serversSmall connectors: Calendar, Email, Maps, Notes, Bank.
4 · Your appsReal data and actions. Results flow back.

Build your own MCP server

A server just exposes tools. This one saves a note, using the official Python SDK.

pip install "mcp[cli]"

# notes_server.py
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("notes")
NOTES = []

@mcp.tool()
def add_note(title: str, body: str) -> str:
    """Save a note and return a confirmation."""
    NOTES.append({"title": title, "body": body})
    return f"Saved note: {title}"

if __name__ == "__main__":
    mcp.run()

FAQ

Is MCP only for developers?

Building servers takes code, but using them does not. Many assistants let you add connectors with a few clicks.

Can the AI act without asking me?

That depends on the assistant’s settings. Good setups ask before sensitive actions such as sending messages or spending money.

Is the answer on this page real?

When live AI is on, yes: it is a real model answering your question. The tool calls are illustrations of what a connected agent could do.

Can it replace a doctor, lawyer or advisor?

No. For health, legal or money decisions it gives general information only. In an emergency, contact your local emergency number.
